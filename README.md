# ✂️ 碎碎念自动截断

一个只做一件事的 SillyTavern 扩展：流式生成时，正文写完（出现完整的 `<content>…</content>` 或 `<talk>…</talk>`）之后，一检测到 `<mutter>` 就自动停止生成，省 token。

## 安装

酒馆 → 扩展 → 安装扩展，填入：

```
https://github.com/Zyzyzy-Dev/ZDJD-CS
```

## 设置

在扩展页面找到「✂️ 碎碎念自动截断」：

- **启用**：需要开启流式输出
- **截断标记**：默认 `<mutter>`
- **起始标记**：默认 `</content>,<talk>`，出现它之后才开始检测；多个用英文逗号分隔；留空 = 全文检测
- **必须先有完整的一对标签**：默认勾上，防止思维链里孤立的 `</content>` 造成误截断

## 注意

- 不要和余温工具箱的「自动截断」同时开启。
- 截断成功时，控制台（F12）会打印 `[碎碎念自动截断] 在第 X 个字检测到 <mutter> → 停止生成`。
